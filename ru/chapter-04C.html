Семинар 1

Основы HTML и CSS

Язык разметки HTML: тэги, атрибуты, сравнение с LaTeX. Атрибут стиля и базовые свойства. Верстка формул с MathJax.
Каскадные таблицы стилей CSS, тэг <style>, селекторы тегов и классов, наследование свойств, специфичность.
Блоковая модель: содержимое, внутренние и внешние отступы, граница. Сокращённые свойства. Свойства display и position, группа свойств inset. Единицы измерения длины, абсолютные и относительные единицы.
*Селекторы по id и значениям атрибутов, комбинаторы, псевдоклассы и псевдообъекты. Макеты flexbox и grid.

Семинар 2

JavaScript

Основы синтаксиса языка: переменные, циклы, ветвления, функции. Сравнение с C, Python и Wolfram. Типы данных: числа, строки, массивы, множества, отображения. Браузерная консоль разработчика, метод console.log().
Связка с HTML: тэг <script>, структура объектов документа (DOM), методы .querySelector и .querySelectorAll.
Интерактивность: атрибут onclick, базовые элементы интерфейса, обработчики событий.
*Планировщики выполнения setTimeout и setInterval.

Семинар 3

Векторная графика и анимация

Формат SVG, атрибуты внешнего вида и атрибуты представления (CSS). Тэг <path> и синтаксис атрибута d. Структура документа, тэги <g>, <def> и <use>. Встраивание векторных изображений из Adobe Illustrator.
CSS переходы (transition) и анимация по ключевым кадрам (@keyframes), параметры интерполяции. Свойство transform. Пользовательские свойства (CSS переменные).
*SVG тэги <animate> и <set>.

Семинар 5*

Хостинг веб-страниц и основы Git

Ссылки на внешние стили, скрипты и изображения в HTML, атрибут defer.
Создание репозитория на GitHub, хостинг веб-страниц через GitHub Pages, структура репозитория, деплоймент через GitHub Actions. Загрузка и редактирование файлов.
Локальное клонирование git репозитория. Синхронизация с удалённым репозиторием: команды git fetch, git status, git pull и git push. Внесение изменений: git diff, git add, git commit. Отмена изменений: git restore (--staged), git checkout, git reset (--hard).

Семинар 6*

Растровая графика в HTML

Контейнер <canvas>, базовые методы для задания стиля и отрисовки графических примитивов, вставка растровых изображений. Составные пути: метод .beginPath и методы добавления сегментов, сравнение с форматом SVG. Прозрачность и режимы наложения (.globalCompositeOperation).
Анимация: метод requestAnimationFrame, очистка холста.
*SVG фильтры. Связка с GLSL шейдерами.
